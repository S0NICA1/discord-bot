# بوت توني الصوتي (Tony Discord Bot)

بوت ديسكورد مصمم باستخدام `py-cord`. يدخل الرومات الصوتية، يستمع للأعضاء باستخدام نموذج الذكاء الاصطناعي `Whisper` (مجاني ومحلي) للتعرف على الكلام العربي، يرد عبر `Gemini 3.1` بشخصية توني الرهيبة، ويتحدث بصوت طبيعي باستخدام `ElevenLabs`.

## ⚙️ المتطلبات الأساسية
- Python 3.11 أو أحدث
- مكتبة الفيديوهات والصوت `ffmpeg` (يجب تحميلها وتنصيبها في نظامك إذا كنت تشغل البوت محلياً)

## 🚀 طريقة التثبيت والتشغيل محلياً

1. **تحميل المكتبات:**
   افتح موجه الأوامر (Terminal) في مجلد المشروع ونفذ:
   ```bash
   pip install -r requirements.txt
   ```

2. **البيانات السرية (Environment Variables):**
   انسخ ملف `.env.example` وغيّر اسمه إلى `.env`، ثم أضف المفاتيح السرية الخاصة بك:
   ```env
   DISCORD_TOKEN=مفتاح_بوت_ديسكورد_هنا
   GEMINI_API_KEY=مفتاح_جوجل_جيميني_هنا
   ELEVENLABS_API_KEY=مفتاح_إليفِن_لابز_هنا
   ELEVENLABS_VOICE_ID=معرف_الصوت_هنا
   ```

3. **تشغيل البوت:**
   ```bash
   python bot.py
   ```
   *ملاحظة: أول مرة يتم تشغيل البوت سيقوم بتحميل نموذج Whisper الصغير (حوالي 500 ميغابايت).*

## 🎮 أوامر البوت

بعد إضافة البوت للسيرفر، استخدم أوامر اللاش (Slash Commands):
* `/join` : لاستدعاء البوت للروم الصوتي الذي تتواجد فيه.
* `/leave` : لطرد البوت من الروم الصوتي.
* `/ask [نص]` : توجيه سؤال نصي لتوني وسيقوم بالرد عليه صوتياً داخل الروم.

## 🗣️ كيف تتحدث مع توني؟
بمجرد دخول توني للروم، يمكنك التحدث، لكنه لن يرد عليك إلا إذا استخدمت كلمة التنبيه (Wake Word):
**"يا توني"** أو **"tony"**. 

*مثال للحوار داخل الروم:*
> أنت: "يا توني وش رأيك نلعب فالورانت الحين؟"
> *ينتظر البوت ثانية ونصف ليتأكد أنك انتهيت من الكلام...*
> *يقوم بمعالجة كلامك...*
> *يرد توني بصوت سعودي:* "لا، هذي فكرة سيئة بكل الاتجاهات الصدق."

## 🌐 رفع البوت على خوادم Railway للعمل 24/7

المشروع جاهز ومُعد للرفع مباشرة على خوادم الاستضافة مثل Railway أو Render:
1. ارفع الكود على حسابك في GitHub.
2. في موقع Railway، قم بإنشاء مشروع جديد واسحب الكود من GitHub.
3. ملف `Procfile` سيعطي الأمر `worker: python bot.py` للتشغيل.
4. ملف `runtime.txt` يؤكد استضافة بايثون 3.11 اللازمة لـ Pycord.
5. لا تنسَ الذهاب لتبويب `Variables` في Railway وإضافة المفاتيح السرية (`DISCORD_TOKEN`, `GEMINI_API_KEY`, وما إلى ذلك).
